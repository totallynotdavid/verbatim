# Verbatim manual

Start with [SETUP.md](../SETUP.md) to get a deployment running. Each page below
covers one workflow, with the code that implements it.
[ARCHITECTURE.md](../ARCHITECTURE.md) maps the code and data model.

1. [Capturing a lesson](capture.md): record a Meet call with the Chrome
   extension, and what each panel state means.
2. [Sign-in, pairing and access](auth.md): roles, consent, who can read and
   write what, and how recordings are served.
3. [Reviewing a lesson](lessons.md): the transcript, playback and notes.
4. [The study loop](study-loop.md): the review queue, SM-2 scheduling, retry
   recordings and trends.
5. [Mock-interview coaching](interview.md): the question bank, tagged answers
   and rubric feedback.
6. [Pronunciation scoring](scoring.md): the optional WhisperX and OpenPronounce
   workers, how drafts are chosen, and how they are authorized.
